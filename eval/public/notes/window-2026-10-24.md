## Limits and attempts

Memory latency is not comparable because of concurrency, pauses and scheduling. SciFact NV paused during queries; reranker ingestion reused the existing corpus (19.9s warm reuse), so it is not a cold-build comparison. Graphiti 0.31.2 native edge extraction requests 16,384 output tokens; this window caps it to the shared 8,192 ceiling on a 32,768-context endpoint. Hyperag graph rows use the documented exploratory rule and are separate from graph-off profiles. See `transport-retry.md` for historical retry cohorts and the common reset policy.

Earlier failed attempts were preserved and replaced by complete retries: Graphiti 105 answers (native output budget), Hyperag NV schema initialization, DMR/oracle NV connection resets. The abandoned 18-answer EmbeddingGemma2 oracle scheduling attempt and later 384-answer held attempt remain unscored. S100 NV 53-answer timeout and the four NF/ArguAna embedding transport failures have no completed replacement. LangMem is blocked by native auto-tool selection HTTP 400, not a score of zero.
